# Training Tracker

This is the public, read-only phone view of the Desktop Calisthenics Tracker. It is generated from the same frontend files as the Desktop app. The Excel workbook is available at [data/calisthenics_training.xlsx](data/calisthenics_training.xlsx); the site reads a snapshot derived from that workbook.

To refresh this site after logging locally, rebuild the phone view using the current Excel workbook, then copy the rebuilt `phone-site/dist/` contents into this repository and push the changes.
